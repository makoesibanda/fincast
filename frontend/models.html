The ensemble weights were tuned via grid search on the 2023 validation set to maximise Sharpe ratio. The optimal weights (GRU=0.9, LR=0.0, TF=0.1) confirm that GRU dominates the available signal — the algorithm assigned zero weight to Linear Regression. This provides empirical evidence that GRU captures the majority of the predictable structure in daily BTC returns on this dataset.
